# Conversational-Image-Classifier

ABSTRACT
This project is an AI-powered web application designed to classify food images and provide informative responses to user questions about the food item. It leverages the CLIP model for visual classification, identifying the food type based on a given image, and integrates a large language model (Mistral-7B via OpenRouter) to generate expert-like responses. With an intuitive Streamlit interface and real-time deployment using PyNgrok, the system enables users to explore food awareness, make healthier choices, and interact with a virtual food expert all by simply uploading a picture and asking a question.
